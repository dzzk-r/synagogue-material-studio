Режим разметки стен / Mask editor

Можно добавлять области стен и «защищённые» объекты. Выберите тип, затем последовательно укажите вершины на фотографии и нажмите «Завершить полигон». Работает и касанием.

Совет: чтобы сохранить настенные картины, лампы или часы, обведите их в режиме «Защитная маска». Чтобы убрать предметы из варианта реконструкции, отключите «Сохранять отмеченные предметы». Мелкие детали и восстановление фоновой стены требуют ручной доводки.

Для подстановки на стены пока используются условные процедурные образцы, поскольку рекламные фотографии не являются бесшовными развертками панелей. SKU отсутствует на публичных карточках; числовой код модели здесь внутренний и не означает артикул поставщика.

Проект работает в браузере, без собственного сервера и подписки. Официальные миниатюры загружаются непосредственно с сайта Kalkir, при их загрузке браузер обращается к поставщику. PNG экспортирует текущий вариант, JSON сохраняет маски и настройки. Испытательный инструмент для обсуждения дизайна, не исполнительная строительная документация.
