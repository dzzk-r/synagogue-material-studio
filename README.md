# Synagogue Material Studio

Interactive browser-based prototype for visualizing wall cladding selections in a synagogue using Kalkir model names and published specifications.

## Public demo / privacy
- This **public repository does not contain original interior photographs**, private JSON project files or sensitive image assets.
- Load your own photographs locally in the browser. They are not uploaded to a server by this application.
- Catalog pictures are linked to the supplier's website. Model-image reproduction and exact tile-layout fidelity are not guaranteed; substitute textures may be marked as illustrative.
- For precise installation decisions, validate product dimensions, seams, quantities, fire classifications and licensing with Kalkir directly.

## Deployment
GitHub Pages can serve this static `index.html` from `main` / `(root)`. Configure under **Settings → Pages → Deploy from a branch**.
